INTERPRETATION (for the paper)
- A server-side admission check is itself check-then-act: it reads state at admission start, the DELETE commits
  ~20 ms later, and a write in between is not seen. Enforcement must bind the invariant to the commit itself
  (same-object precondition / transactional check), not merely move the check to the server.
- This turns E38 from a by-construction counterexample into a measured result with a mechanism.
