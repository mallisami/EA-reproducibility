# Scientific scope and stopping rule

This is not a new broad experiment campaign. It is a targeted primary-observation-path confirmation for A4d.

The earlier two-host A1 and A3 evidence remains valid and is not repeated. The new A4d data are interpreted regardless of scientific direction. The only pass/fail gates in this package concern **instrumentation integrity and schedule completeness**, never whether A4d produces a favorable outcome.

After one complete audit-safe A4d main run, stop experimenting and integrate the result. Do not extend the delay grid, add repetitions, or rerun because of an unfavorable scientific result.
